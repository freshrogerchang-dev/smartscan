## 本輪三個切片
1. 可還原裁切 → 預覽 → OCR/PDF 使用同一範圍；無可靠邊界時不猜。
2. 規則命名／分類 → 使用者修改 → IndexedDB 原子儲存 → 重新載入與全文篩選。
3. 已辨識／核對的每頁文字 → Unicode 字型 → 隱藏 PDF 文字層 → 用獨立 reader 擷取查核。

## MVP 結案與後續
保存必須等待 transaction complete，寫入失敗不得顯示成功；缺文字時不得假稱可搜尋。圖片變更須清除該頁舊文字，頁序變更須同步文字順序。
瀏覽器配額與資料回收無持久性保證，需保留 PDF 備份提醒。自製資料的桌面測試不能取代 iPhone/HEIC 或實際文件品質驗收。
目前 1–13 有實作與限定測試，14–15 僅實驗接入，不能宣稱 15 項全部完成。下一輪需取得可用的本機文字／影像模型環境，再驗摘要、問答、手寫、公式；若改成雲端服務，必須先取得使用者變更「文件不傳出裝置」決策的明確同意，再補 S1–S3 的新選型與資料流。
